# LifeGameDemo

ライフゲームデモ

## 必要なライブラリ

- M5Cardputer

## Arduino IDE 設定

- 開くファイル: `LifeGameDemo.ino`
- ボード: `m5stack:esp32:m5stack_cardputer`

## 概要

- 240x135 の全画面をそのままセル空間として使用
- 起動時にランダムな初期盤面を生成
- 生存セルごとに色相を持ち、新しく生まれたセルは親 3 セルの平均色を受け継ぎつつ少しだけ変異
- 世代更新は画面端をつないだトーラス形状で計算
- 生死が変化したドットだけを書き換えて高速に更新

## 使い方

1. Arduino IDE で `LifeGameDemo.ino` を開く
2. ボードを `m5stack:esp32:m5stack_cardputer` に設定する
3. ライブラリマネージャで `M5Cardputer` をインストールする
4. 書き込むとランダム初期盤面から自動でライフゲームが始まります

## 操作

- `BtnA` または `R`: 盤面をランダム再生成
- `Enter` または `Space`: 一時停止 / 再開
- `↑`: 1 ステップの更新インターバルを短くして速くする
- `↓`: 1 ステップの更新インターバルを長くして遅くする

## 配線 / 前提

- Cardputer-ADV 単体で動作します
